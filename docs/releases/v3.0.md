# Nalomu Note v3.0

从 Electron 迁移至 Tauri 2、Vue 3、TypeScript、Vite 和 Tiptap，继续保持单便签定位。

## 功能

- 透明无边框、拖动缩放、置顶、托盘隐藏与恢复、单实例运行。
- 标题、列表、待办、引用、代码块、链接和富文本；浮动格式面板与中文右键菜单。
- 本地图片导入、剪贴板图片粘贴、等比例拖动缩放；图片作为持久附件保存，不依赖源文件。
- 独立外观设置窗口；本地自动保存、有效备份与损坏数据保护。
- 依赖更新统一验证；CI 同分支只保留最新检查。

## 下载与启动

- macOS Apple Silicon：下载 `Nalomu-Note-aarch64-apple-darwin.zip`，解压后打开 `Nalomu Note.app`。
- macOS Intel：下载 `Nalomu-Note-x86_64-apple-darwin.zip`，解压后打开应用。
- Windows x64：下载 NSIS `.exe` 安装包并运行。
- 下载后使用 `SHA256SUMS.txt` 核对校验值。macOS 为 ad-hoc 签名，未做开发者签名或公证；Windows 未签名，系统可能提示确认打开。

## 数据与兼容

新版本从空便签开始，不导入或修改旧版 `config.json`。数据保存于系统应用数据目录，备份时需同时保留 JSON 与 images 目录。schema 1 会升级为 schema 2，高版本数据不降级。

## 安全和验收

完整锁文件依赖纳入 pnpm audit 与 cargo audit。Tauri 2.12 消除了五项 unic 未维护警告；保留的 proc-macro-error 与 glib 警告属于 Linux GTK 依赖链，macOS/Windows 目标不编译，首版不支持 Linux。详见仓库 docs/security.md。

此版本按维护者要求正式发布。macOS Apple Silicon 图片粘贴、缩放及重启恢复已有原生验证；Windows 和 macOS Intel 原生验收、真实中文输入法与不同 DPI 验收仍未完成，CI 构建不替代原生验收。详见 docs/acceptance.md。
